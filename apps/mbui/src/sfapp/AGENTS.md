# still.fail app test sweeps, budgets, replays, and media (for agents)

## Screen sweeps, overflow, and hang categories

- Sweep every screen at default text scale (`corners_wbtest.mbt`) and in a phone window at 1.3x system font scale (`apps/mbui/src/sfapp/words_large_wbtest.mbt`). Add a fixture mode in `corner_modes` for any new state reported in a bug.
- PostHog hang reports (`ui_hang`, `ui_hang_summary` in `apps/mbui/src/stillfail/reports.mbt`) record only literal `shown_kind` screen names, never chat, station, or file identifiers. Register every new screen kind in `shown_known` (`apps/mbui/src/sfapp/shown_wbtest.mbt`).
- Both sweeps enforce `Tester::fixed_outgrown` (also in `t.audit()`): boxes containing text must grow with font scale (as `list_looks_at` does), or fixed-size marks (letter squares, `!` badges) must opt in via `@sf.mark_words_node` (`View::box(words_as_said=true)`). `corners_outgrown_known` and `words_large_outgrown_known` only fall.
- `apps/mbui/src/sfapp/switches_still_wbtest.mbt` presses every screen switch against a core delayed by 400 ms (main-only `switches` job): each press should change visible UI once (`switches_known_wbtest.mbt` only falls). Exclude cross-page elements (notices, tips, live counters) by kind, never by screen name.

## Real-size frame and binding budgets

- `apps/mbui/src/sfapp/real_size_wbtest.mbt` opens every screen on real-size core payloads (`apps/mbui/src/sfrealsize`, generated by `client/core-ts/test/real-size-app.test.ts`, never edited by hand) and applies every workspace change reaching its topics.
- Regenerate `apps/mbui/src/sfrealsize` in the same change whenever a core topic shape or payload changes. Update rows when adding a topic to a page or moving an old view onto nodes.
- Bars in `real_size_known_wbtest.mbt`, `real_size_change_known_wbtest.mbt`, `real_size_bindings_known_wbtest.mbt`, and `chat_nodes_open_budget_wbtest.mbt` only fall (`scripts/mbui-budgets.ts` checks commits and CI against `apps/mbui/src/sfapp/fixture_open.mbt` and `client/core-ts/test/real-size.ts`). Any raise requires a dedicated `Budget-raise: <why>` line in the commit message, allowed only for newly displayed content or legacy `Ctx` work newly counted as nodes.

## Replay topic bytes and trace switches

- Recorded flow traces enforce core payload budgets in `apps/mbui/src/sfreplay/topic_bytes.mbt` (whole KB, repeated whole KB, dropped-topic messages, largest single value). Re-recorded traces that send less lower the bar, and traces that send more fail.
- Older traces use `@sfcore.trace_switch` (`trace_switches`) so replays match what their recording asked. The count of traces missing each switch only falls (`apps/mbui/src/sfreplay/flows/trace_switches_test.mbt`). When the app removes an old query, keep replay-only shims in `apps/mbui/src/sfreplay/source.mbt` (`MBUI_STATION_ROWS` via `@core.Replay::keep_stations`, `MBUI_CONNECT_ROWS`, `MBUI_PROFILE_ROWS`).
- Every trace records host settings (`@ui.trace_settings`, refused if missing in `Flow::start`). Record traces in UTC via `apps/mbui/e2e/run.sh`. Legacy traces use `"from":"replay"`.

## Offscreen stills, video, and latency

- Generate stills and videos after reading and updating code logic. Prepare `apps/mbui/scripts/media-job.sh picture` per source state and reuse its Wasm renderer across scenes. Use `film` for video. Build unpublished renderers on the build station with `apps/mbui/scripts/media-dev-build.sh KEY INBOX "" mbui-film-wasm` inside a station task mirror (no `.git` or `MBUI_TOOLS` needed). Never build native `sffix` (`apps/mbui/scripts/mac.sh`) for stills.
- Build UI proposals and mockups as real mbui views (`apps/mbui/src/sffixture`) rendered offscreen, never HTML or CSS.
- Render stills for people at `MBUI_FILM_SCALE=3`, at rest, in the target state (panel or menu open when relevant), and with zero new `rules:` (`Tester::audit`) faults.
- Never run screenshot diffs on devices, emulators, simulators, or desktop windows (detlint `device-shot`). Measure real-host input latency for people via medians of alternating runs (`apps/mbui/scripts/latency.sh`), never as a CI check.
