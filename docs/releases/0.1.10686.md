- 新增：Connect 与 station 支持「自动分配白名单」：新对话只在勾选或加入白名单的在线 station 间按实时负载分配，白名单为空时明确提示，不会落到未勾选的机器
- 新增：Station 离线或无响应时显示本地连接诊断（失败原因、重试计划、各路径拨号结果，可一键复制），资源、进程与设置页保留离线前的只读快照
- 新增：设置「密钥」页可创建和管理团队共享的 Workspace 密钥库；设备配对与密钥库授权弹窗显示 6 位核对码、所属人与授权范围，配对时一次生物识别即可交接个人密钥库
- 新增：Windows station 设置页的「远程控制 UAC 与锁屏」开关，人工远程控制可操作 UAC 安全桌面、管理员窗口与锁屏界面，agent 仍是普通权限
- 新增：远程画面「超清」（1440p）档位；Mac 与 Windows 上支持右键与中键长按拖动、游戏鼠标锁定（⌃Esc 解除）；macOS 与网页版可把本机麦克风共享给远端应用
- 新增：桌面端对话里已在本机的图片、视频和文件，右键可「在访达中显示」（Windows 为「在资源管理器中显示」）；图片查看器支持触控板双指左右切换；双指滑动返回显示跟手的返回标记
- 新增：管理后台可生成与吊销管理员 API 密钥，并有 `stillfail admin` 命令行；station 可在 config.json 用 maxConcurrentTurns 限制并发会话数
- 改进：大屏上点开文件、网页服务、可视化、图片和音视频默认从缩略图放大到全屏预览，⌘/Ctrl + 点击或「在侧边打开」放进右侧栏，侧栏里的图片可直接标注和左右切换
- 改进：小屏底栏改为液态玻璃胶囊和独立的 ＋ 按钮；小屏、中屏、大屏的页面切换加入分层视差与压暗，手势跟手、打断时速度连续
- 改进：新对话预设选择器改为结构化面板，可搜索、常用优先、直接编辑；新建/编辑预设弹窗字段更清楚，编辑时不再丢失模型速度与上下文窗口
- 改进：同一个 Slack 线程里叫起的多个 agent 合并为一条对话；宽页对话右侧目录刻度悬停展开可搜索的「对话目录」
- 改进：大文件传输在直连被限速时自动走更快的中继，多条链路可用时并发拉取；慢中继下的下载与图片预览更快
- 改进：长时间使用时内存占用更少；文字排版、账号概览页和安卓长段中文更快；大站存储维护与归档多的 station 不再长时间占满 CPU，磁盘不足时自动回收闲置数据与共享 clone
- 修复：严格限制闲置会话进程数，按机器内存调整并发、收紧失效账号自动重试，避免换号或集中唤醒打满 station 内存；取消默认的全局并发上限，普通对话不再被静默排队
- 修复：后台任务与定时提醒叫不醒空闲或 station 重启后的冷态会话
- 修复：某条中继半坏（能 ping 通但连不上）或流量用尽时，station 不再误判自己失联而断开所有设备；中继每日配额只计出站流量；客户端不再经 DHT 连入已下线或未配置的中继
- 修复：Windows 上迁移状态文件写入冲突可能导致 station 崩溃；归档打包与配置落盘遇到短暂文件锁时自动重试；未配置 Windows Hello 时密钥库降级到 DPAPI
- 修复：Claude 账号续期失败或额度不可用时不自动切号、「重新分配」无效；Antigravity 账号要求验证时显示完整的验证链接，自动切号不再选它；订阅额度恢复后下一轮立即切回订阅
- 修复：手机已开启密钥库后新批准的电脑仍显示「密钥库未开启」；同步中修改的共享记忆可能停在本机；关掉 Profile 分享后其他 station 仍在用副本
- 修复：Mac 休眠、息屏或外接显示器唤醒后窗口画面卡住不刷新；Mac 网页输入框按 Option+左箭头误触发后退；Windows 按钮文字偏下、展开右侧栏时顶栏按钮撞进窗口控制按钮
- 修复：对话上翻加载更早消息时画面跳动、窗口变窄折行时压住下方内容；发消息时新消息首帧与上方重叠；同一行文字后的 \[…\] 公式显示成乱码；网页版偶尔串字；iPhone Duo 外屏打开 App 可能闪退
- 修复：⌘K 搜索支持多词匹配并跨站按相关度排序；Comma 拒绝连接时显示原因和下一步；monoid 网页版标签页标题显示成 still.fail；从 console.monoid.computer 加入工作区报「missing account」
