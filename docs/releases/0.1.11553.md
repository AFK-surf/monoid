- 新增：支持 GitHub Copilot 作为 agent 运行时：在「软件」页安装后用 GitHub 账号登录即可使用，可查看可用模型和高级请求余量；Copilot 账号可以用自己目录下的 MCP 服务和技能，格式与 Copilot CLI 相同
- 新增：对话菜单里可以把对话迁移到另一台 station，迁移过程中对话页提示迁往哪里，并暂停发送
- 新增：全新的字体与排版设置页：推荐风格一键套用，界面、正文、代码的中西文字体分别搭配，正文字号、行距、中西文自动留白和代码连字都可调
- 新增：设置 › 此设备 › 网络与同步，可以关掉「同步所有 workspace」，只同步当前 workspace，更省电省流量
- 新增：设置 › 备份可以调节备份上传限速（默认 8 Mbps，也可以不限速）
- 新增：Profile 的「可用的 station」可以选「跟随工作区白名单」，白名单变了自动同步；Profile 列表可多选，批量开启、停止分享
- 新增：外观的「主题色」多了「五彩色」，每次打开随机挑一种；没设图标的 station 显示所在系统（macOS、Windows、Linux）的图标
- 新增：实验性功能「按住 ⌘/Ctrl 点击引用」中，按住 ⌘ 拖动按整词选字，按住 ⌘⇧ 拖动按整句选
- 改进：远程桌面和远程浏览器画面更稳：发包节奏、抗乱序、码率与分辨率控制都重做了，远程浏览器改用实时 H.264 视频流
- 改进：多台 station 在线时，客户端空载的 CPU、耗电和发热大幅降低；不在 station 页面时不再推送各机器的实时指标
- 改进：station 的对话列表、归档、重连同步更快；会话很多或备份文件很多时，备份不再长时间占满 CPU，也不再占满上行带宽
- 改进：station 内置浏览器占满 CPU 时不再拖慢 station 本身；内存不足时系统先杀 agent 跑的程序，不再先杀 station，并告诉所属的对话
- 改进：图片和视频预览改为全幅显示，控制栏自动淡出；视频触控横滑可以精细拖动进度
- 改进：Station 列表改成紧凑的两行分组布局，一屏看到更多；只执行任务的机器单独成组
- 改进：启动更快，密钥库页面和卡片更早可用；搜索时本机已缓存的对话立刻出现
- 改进：传输列表显示总大小和下载速度，排队中的文件可以立即开始
- 改进：菜单、弹出框、滑块、复选框、分段选择等更多控件统一成液态玻璃样式，更接近 iOS 27
- 修复：加入了多个工作区的 station 在大量设备重连时，主线程被反复读文件卡住、请求超时
- 修复：非安全模式下，工作区里有成员从没连过这台 station 时，没法创建或同步 Workspace 密钥库
- 修复：部分设备失效或移除后，个人密钥库变成「库不存在，或你不是其成员」，批准保存时还会分裂出重复的个人库
- 修复：对话归档或批准后，密钥「待批准」卡片残留、一直转圈
- 修复：安卓设备关闭过锁屏后，密钥库提示密钥失效却无法恢复；重启客户端后密钥库短暂显示「这台设备未获此库授权」
- 修复：Antigravity 额度用完的提示接在回复后面时会话卡住；Linux 和 Windows 上 Antigravity 账号登录后显示已退出、多个账号串用；macOS 上升到 1.5.17 后多个账号串用钥匙串；企业账号填完项目 ID 后卡住
- 修复：一台 station 转发给另一台的请求接连没回应后，两台之间的连接卡死，期间转发的飞书消息丢失
- 修复：station_task 在任务很多时 list 报 head too large；station 意外重启后中断提示把起过名的对话显示成「新对话」
- 修复：新对话刚建立时恰好做了备份，从这份备份恢复会缺少该对话的会话记录
- 修复：Station 用了 App 还不认识的新运行时时，对话整页打不开，现在提示更新 App
- 修复：macOS 远程桌面在锁屏密码框粘贴不了密码；macOS 输入法组字时按左右键后输入异常；macOS/iOS 首次打开可能不弹通知授权
- 修复：窄窗口点「新对话」后拉宽，侧栏原来的对话仍显示选中、点了打不开；互动卡片的文字不能选中复制；已归档的子对话顶部没有上级对话的面包屑；agent 跑耗时命令时一直显示「加载工具」等多处界面问题
