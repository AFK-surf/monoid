- 新增：Profile 可以把订阅账号额度分享成图片（可打码），概览多了「输出速度」图表；用量页展示工作区 agent 的实时输出速度
- 新增：执行历史顶部在 agent 运行时有「停止」按钮；悬停 GitHub Actions 运行链接可看进度和步骤
- 新增：大屏侧栏里的文件、网页服务、可视化和小程序可以全屏查看；网页版和桌面版可以用触控板两指右扫返回
- 新增：station 连不上时排队待发的消息可以编辑或删除；Station、连接、Profile 和已归档列表的行支持右键菜单；快捷键页面可以搜索

- 改进：设置 › 安全重新整理为「我的设备」「其他成员」「Station」三组；迁移时「迁到」列出所有其它 station，不能迁入的写明原因
- 改进：打开对话更快：不再重读整个 Slack 历史、不再重复解析没变的消息，打开对话和实时事件不再被后台同步阻塞；大图先下预览图
- 改进：模型选择默认只展示当前 station 可用的模型；按 Codex 账号支持的模型显示 Ultrafast
- 改进：按钮、开关的手感反馈，深色模式下菜单和弹出面板更清楚，长列表滚动和毛玻璃更省电不掉帧
- 改进：Windows 上 station 更新时 launcher 也无感换成新版本；Mac、Windows 版重新打开时恢复上次的窗口大小和位置
- 修复：station 长时间运行后句柄耗尽，账号检查超时显示「不可用」
- 修复：本机 CLI 二进制损坏或缺失原生包（如 Windows 上 claude 占位文件）时，station 启动后反复崩溃重启
- 修复：station 更新时若有 agent 进程还没建立会话，新 station 不再接管它；同一条消息启动失败后不再连续重试三次各等 2 分钟
- 修复：station 的 mesh front 在 accept 意外结束时会干净退出并重启，front 重启后也会保留中继与拥塞控制设置
- 修复：Windows 上「软件与更新」一直显示正在检查版本、Station 与运行时显示未安装且无法自动更新；Windows 直连 Windows 时线路一直显示「正在选择线路」
- 修复：station 升级到加了新协议的版本时，其他 station 和设备一段时间内连不上它；多 station 工作区里设备连接其他 station 偶发报 403
