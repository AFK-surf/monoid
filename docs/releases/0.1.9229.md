- 新增：同一个 workspace 的各台 station 共用一份记忆和 skill，在一台上记下的，别的 station 上的 agent 下一轮就能看到
- 新增：预设和收藏的模型跟着人走，同步到你的每台设备和工作区的每台 station；预设菜单只列自己的，别人的在「其他成员的预设」里查看、使用或复制
- 新增：agent 可以协助迁移 station，开始和交接两步在 app 里点卡片确认，后台任务、记忆和 skills 一起迁过去；迁移期间两边都不自动更新
- 新增：station 出了新版本且没开自动更新时，像应用更新一样提示，可以在弹窗里逐台更新
- 新增：对话报错且查到账号额度已用完时，提示里说明并带「重新分配账号」按钮；「回复即可继续」的提示也带重试按钮
- 新增：agent 可以申请删除密钥库里的密钥、撤回不再需要的密钥申请；agent 开 chat 时可以选预设，也能设 Fast 和上下文长度
- 新增：新扫码创建的飞书/Lark 机器人自带云文档、知识库、云盘、表格等常用权限；Linux 版可以把文件和文件夹拖进窗口
- 新增：设置里可以试用新对话页（默认关闭）；用鼠标键盘时对话列表滚到顶后继续往上滚会露出搜索框
- 改进：安全模式的升级在 station 更新后自动完成，不需要任何人操作；还没更新的 station 在「设置 › 安全」里列出，可一键更新
- 改进：station 浏览器改成普通浏览器的用法（标签页、地址栏、前进后退刷新）；远程控制只留一行栏，Mac 桌面可以按窗口查看
- 改进：station 的名字和图标存在 station 自己身上，同一台机器在各个工作区里是同一个名字
- 改进：Slack 里用 /sf 选模型时先列常用和配置里点名的模型，输入名字再搜索全部；选择图标分成「图标 / Emoji / 图片」三页
- 改进：workspace 设置里的「连接方式」改名为「中继」，并区分自定义中继和官方中继；归档后的「撤销」留在原来那一行
- 修复：station 更新后 front 意外退出时 station 长时间连不上、要手动重启；Linux 上记忆同步监视 agent 目录里的代码仓库和依赖，目录很大时 station 卡住或失联
- 修复：station 更新时新进程偶尔因「database is locked」启动失败，更新没有生效；另一台 station 重启后，发给它的请求不再卡 30 秒以上
- 修复：一台 station 同时加入多个工作区时，成员可能凭另一个工作区的身份在本工作区被当成所有者或管理员
- 修复：Claude 换了限额报错的说法后对话反复报「模型服务出错」、不换账号；借用其他 station 的登录时对方续期慢导致对话中断
