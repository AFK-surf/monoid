- 新增：一台 station 连不上时，可以在对话的「…」菜单里选「在其他 station 接着做」，从备份在另一台 station 上开一个新对话接着做，原对话保持不变
- 新增：设置 › 进度汇报：你发起的会话多久没发消息时提示 agent 汇报，以及要求汇报还是提醒汇报，同步到所有设备
- 新增：设置里新增「MCP 服务」页面，集中管理各 Station 的第三方 MCP 服务，并控制是否允许其他 Station 共享使用
- 新增：Station 设置的软件列表里可以按 runtime 启用、禁用或卸载运行时
- 新增：Station 可以自动发现局域网里的 AirPlay 设备（Apple TV、HomePod 等），用 4 位 PIN 配对后由 agent 遥控、投放视频和音频
- 新增：远程桌面默认开启跨系统快捷键映射（Windows/Linux 与 macOS 之间自动转换 Ctrl/⌘ 和按词、按行编辑键），Mac 控制 Windows/Linux 时可以把 ⌃ 保留为 Ctrl
- 新增：在网页上打开 gcloud 等一键登录卡片时，可以改用验证码登录
- 新增：Geisha（.gsa）代码块语法高亮与代码文件预览
- 改进：外观里的液态玻璃通透度改为「界面材质」三档：液态玻璃、磨砂玻璃、实色；菜单、弹窗和提示条换成更通透的液态玻璃，深浅色下文字依然清楚
- 改进：Station 列表第二行改为位置固定的 CPU、内存、磁盘、网络图标，只有告急项变色
- 改进：对话列表按项目分组时，「未归类」固定在最上面，各项目按名称固定排列，不再随对话活跃而跳动
- 改进：远程桌面的串流分辨率（含 2160p）、码率上限、4:4:4 色彩和受控端显示分开设置
- 改进：图片和视频预览的控制栏不再自动隐藏，只在单击时显示或隐藏
- 改进：系统开启「减少动态效果」时，界面样子与平常一致，只是不再有过渡动画
- 改进：备份按网络延迟自动放慢，上行较慢时不再占满网络
- 修复：删除文件到回收站时，已在回收站里的同名失效链接被覆盖或删除失败
- 修复：Android 与桌面端在后台和空闲时持续占用较高网速
- 修复：网络很慢时，station 因备份超时把完整备份发到越来越多的 station 上；限速下首次备份同步较久时报 ENOENT 中断并从头重传
