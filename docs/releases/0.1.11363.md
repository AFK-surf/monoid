- 新增：聊天里预览 PDF、Markdown、代码和纯文本文件时可以选中文字复制、引用或加批注；代码与纯文本显示行号，可以按行引用
- 新增：子会话列表顶部下拉出搜索框，按标题、状态和对话正文搜索子会话
- 新增：网站登录卡片右上角可以手动取消登录，agent 也能撤回没完成的登录卡片

- 新增：Web 和桌面端支持触控板双指左滑前进
- 新增：实验性功能「戳一下」：选中聊天里的文字点「戳一下」，由小模型结合上下文直接回答；实验性功能「按住 ⌘/Ctrl 点击引用文本」：按住 ⌘（Windows/Linux 为 Ctrl）点消息里的一句话，直接引用进输入框
- 改进：远程无头浏览器默认按 1280×900 投屏，可以切画质，弱网时自动降画质减少卡顿
- 改进：多台 station 在线时后台概览推送和本地写库大幅减少，手机不再持续发热；账号用量趋势页更快
- 改进：自动分配 station 时把 CPU 负载算进去，不再把新对话派到 CPU 已满的机器
- 改进：手动归档的 Slack、飞书等外部对话归档后保持安静，再 @ 一次就自动恢复
- 改进：液态玻璃的高光、边缘、按压手感更接近 iOS 27，不再发灰、发白、有锯齿；小屏二级页改用单行液态玻璃顶栏；安卓第一次出现液态玻璃时不再卡一下
- 改进：聊天 Markdown 里的强调改用次要文字色正体显示
- 修复：后台整理索引的进程交替时偶尔卡住，之后打开对话、新建对话都一直加载到超时，只有重启 station 才能恢复
- 修复：Linux 上 station 里某个进程（如浏览器）因内存不足被系统杀掉时，整个 station 跟着重启
- 修复：机器文件句柄耗尽（EMFILE/ENFILE）时启动子进程失败，整个 station 崩溃退出
- 修复：高延迟中继下，端到端探针把正常的 station 判成不通并重启、断开连接，重启后又反复这样
- 修复：工作区 skill 很多时，切到 Antigravity CLI 的对话发不出消息
- 修复：安全模式关闭期间新设备接入后卡在「安全 已开启」或「正在同步安全模式的成员名单」，安全模式重新开启后没法重新发起设备审批
- 修复：飞书群或私聊里在主聊天引用回复一条消息并 @机器人 时，回答错发到被引用消息的话题里；飞书等非 Slack 对话里的会话链接显示成乱码
