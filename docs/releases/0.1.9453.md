- 新增：Gemini（Antigravity CLI）订阅可以分享给同一 workspace 的其他 station 使用
- 新增：密钥库可以用 Slack 授权添加你自己的 Slack 账号，agent 也能发卡片请你授权，之后经你批准以你的身份调用 Slack
- 新增：Farview 标签页由 app 直接绘制，滚动、打字和鼠标悬停都在本机完成，网页编辑区里方向键、删除、回车和快捷键都能用
- 改进：额度用完时，同一模型在别的 runtime 的账号上还有额度会自动切过去接着跑；Antigravity 额度用完时自动换账号或模型
- 改进：agent 开对话时区分「自己领导的下属对话」和「为你开的对话」，下属对话的提问只交给领导它的 agent，不再进你的待处理
- 改进：设置中的「记忆」直接展示全 workspace 共享的记忆、项目记忆与技能及最近修改记录；记忆写得过长时 agent 会先精简
- 改进：成员很多的 workspace 里安全模式读取和升级快了几倍，超过 200 人也会自动升级；只用网页版的成员所在 workspace 也会自动升级
- 改进：开了安全模式时，未加入的 station 在 Station 列表和它自己的页面上直接有「加入安全模式」按钮
- 改进：station 常驻内存和主线程占用明显降低，后台索引与副本导出降到后台优先级，不再拖慢机器；主线程卡死或网络前端失联时自动恢复
- 改进：打开对话、再次打开服务与后台任务、agent 卡片和弹窗时不再先闪空白或骨架；长对话中消息更新与新回复到达时更流畅
- 修复：关闭官方中继并添加自建中继后，连接立即切到可用中继，不再因慢路径超时连带断开正常连接
- 修复：借用其他 station 的 Gemini 账号时，会话进程常驻超过一小时后每轮都报「Agent execution terminated due to error」
- 修复：agent 刚结束时来了新消息、或 station 交接时，station 偶尔整个崩溃重启；Mac station 更新后局域网直连可能失效
- 修复：station 数据目录（任务镜像、runner 输出、日志、数据库 WAL 等）无限增长占满磁盘；交接后空闲会话进程不回收
- 修复：点「重新分配账号」报 no route；agent 发的决策卡错派给模型账号；agent 报完「做完了」又接着干活时对话一直显示已完成
- 修复：Codex 账号重新登录后，新消息要等另一个会话的长任务结束才开始处理；station_task 同步到沙箱的文件丢了可执行权限
- 修复：开启安全模式的人设备全部丢失时，其他所有者可以把其移出、重新添加并批准新设备；同一账号设备较多时 workspace 列表偶尔一分钟加载不出来
- 修复：Mac 上新对话发送消息时界面卡顿；Windows 上文字发虚、竖笔彩边过重；Mac 右侧面板打开时按 ⌘W 先收起面板
- 修复：消息里很扁的长条图片只显示中间一段；折成多行的行内代码底色乱条；「引用并评论」发出的消息显示为空行
