- 新增：对话页有主会话、子会话的快捷入口和多级路径；在跑的 agent、station、后台任务、受控屏幕和子会话入口集中到输入框上方的一排胶囊里
- 新增：查看远程浏览器时，顶部列出同一台 station 上的全部浏览器标签页，可直接切换、新建和关闭；远程会话的「新建」可直接开终端或浏览器
- 新增：Markdown 文件阅读时可以切到「源码」看原文；官网与网页端新增中英文技术支持页
- 改进：菜单、弹窗、浮层、顶栏、底栏和按钮统一换成单层液态玻璃，顶栏改为渐进模糊；小屏底栏收紧，列表向下滚动时自动收成圆球
- 改进：打字时输入框背后的消息会渐隐；对话页右下角的「待处理」「对话目录」「跳到最新」合成一个竖向胶囊
- 改进：Windows 长对话绘制、切换页面与长段中文排版、列表滚动和流式输出时更流畅；macOS 打开或离开对话时不再因重建菜单栏卡顿
- 改进：新对话的首次回复更快；Claude 会话发出结束状态后不再多调用一次模型
- 改进：Station 页「资源」卡片显示机器配置；新对话的模型标签用闪电图标标出 Fast 和 Ultrafast；新建对话选了别的 station 的模型时说明账号在哪、为什么不能用
- 修复：账号多、在线设备多的 station 主线程被反复解析配置拖住，导致 app 连不上、消息一直「正在发送」
- 修复：额度用完自动换号时可能换到 OAuth 已失效的账号，对话接连报错停下；现在跳过失效账号并提醒管理员重新登录
- 修复：对话运行中途 station 重启交接后、或 Codex 丢了 MCP 工具连接时无法自愈
- 修复：闲置会话清理被并发任务打断后再也不清理，新格式 MoonBit 模块与本地构建缓存不回收，导致磁盘占满
- 修复：视频播放卡住时选路慢、断流后切换慢；旋转加载图标让毛玻璃每帧重算，手机发热掉帧
- 修复：远程屏幕首帧丢失或弱网丢帧后一直停在「正在连接」，缩放时画面跳动；远程浏览器里 iframe 内的通行密钥登录点不动
- 修复：飞书机器人新建的群或还没有会话的群，现在可以主动发第一条消息；飞书与 Slack 接入的对话选中文字后不显示「引用」
- 修复：对话页加载中或读取失败时一片空白；执行历史里的链接点不开；鼠标停在悬浮卡片上时滚轮滚不动对话
- 修复：安卓 16 上拖动音量条不生效；安卓下拉或上拉越界时输入栏和胶囊被一起拉动
- 修复：小屏子会话抽屉、预设面板、附件抽屉、输入框上方胶囊等多处裁切、错位和放不下的问题
