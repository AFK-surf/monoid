- 新增：对话列表可以切换看板视图，按状态、机器或成员分列查看和管理待派发事项
- 新增：可以用 Pi 处理对话，支持服务商 API key、OpenCode Go、Anthropic key 或自定义环境变量
- 新增：连接可以加入 Group 即时通讯服务器，在它的私聊和群聊里干活
- 新增：可以用公司的 Google 账号（Gemini Enterprise / Google Cloud）登录 Antigravity CLI，Google 账号显示套餐；在 station 的浏览器里登录 Google 时自动读取授权码
- 新增：Profile 有额度与恢复预测、消耗速度的概览图；图片预览可以单击、向下拖动或双指下滑关闭
- 改进：浏览器标签页在本机排版绘制网页，拖动窗口、悬停、滚动和输入即时响应，同一标签页可以在两处同时打开
- 改进：Antigravity 会话会加载工作区与预设技能和仓库的 AGENTS.md / CLAUDE.md 规则；干活途中额度用完也能认出来，自动换账号或等额度恢复
- 改进：文档阅读器和文件预览重做，宽表格可以横向滑动；中文与英文、数字之间自动留出细小间距
- 改进：打开对话、面板、文件页、设置页和新窗口时不再先闪空白或占位，成员头像和文字同时出现；宽屏排版更省电
- 改进：station 归档、打包下载大文件夹、共享技能等工作移出主进程，不再卡住或占用大量内存
- 改进：对话里接连出现的相同报错合并为一条并显示次数；对话框里按回车执行主按钮，菜单上下键到头循环
- 修复：删除、停用或移走一个账号时，用过它的每个对话（包括很久不活跃的 Slack、飞书线程）都被切换账号并各发一条「已切换账号」；现在只切正在运行的对话
- 修复：station 的连接服务在启动或运行中出错（如数据库暂时繁忙）后不再一直离线，会自动重新启动
- 修复：复制或移动文件时，目标与源目录重叠、或文件夹列表超出上限，可能漏传后删掉源文件；现在操作前就拒绝
- 修复：重启应用后，消息草稿里以路径添加的文件和文件夹丢失或变成附件
- 修复：成员离开工作区或删除账号后，其尚未使用的任务机器登记令牌仍然有效
- 修复：关闭官方中继并添加自建中继后，station 之间、网页版和新设备的连接仍走被关掉的中继或连不上
- 修复：Codex 输出很长的一行时 station 读取进程内存暴涨到数 GB；MoonBit 子进程内存持续上涨不触发回收
- 修复：同一台机器上旧版留下的 mesh 端点与新进程互相顶掉连接；station 更新交接、在设置里重启时设备连接全部断开或反复掉线
- 修复：Windows 上 station 更新交接时丢失已授权的保管库凭证；Windows 上从 App 安装 Antigravity CLI 后要重启 station 才能用
- 修复：Antigravity CLI 会话开机网络未就绪时报「Unknown model ID」、迁移后恢复对话报错、工具过多时无法在对话里发消息
- 修复：权限为 0600 的 MEMORY.md 被跳过，各 station 的共享记忆不同步；含独立克隆和 worktree 的对话迁移反复失败
- 修复：Slack 对话里另一个 agent 发的图片和视频一直「暂时无法预览」；「来自 #频道」跳不回 Slack 原消息
- 修复：系统字号调大后部分文字被裁切；同屏公式较多时 Android 与网页上渲染成黑块；新对话第一条消息发出后输入框里还留着这段话
