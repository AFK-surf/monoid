# Working in `pion/tools/mbt2pion-monoid` (for agents)

Monoid-specific configuration, asset generators, verification gates, vertical dual-oracle pilot, and 255-file `@sf` audit scripts for migrating `libs/ui/src/controls` (`@sf`) to `pion/ui/packages/sf` via `AFK-surf/pion/tools/mbt2pion`.

## Key Files

- `manifest.toml`, `api_map.json`, `m1_invar_blockers.json`, `drift_ledger.json`: machine-generated by `node pion/tools/mbt2pion-monoid/audit_signatures.mjs --invar <dir> --invar-sha <sha>` (unit-tested by `node pion/tools/mbt2pion-monoid/test_audit_signatures.mjs`). Never hand-edit SHAs or denominators.
- `recipes.toml`: declarative Monoid/Invar bindings (`signals::Ref`, `signals::signal_by`, `#derive(Eq)` / `ignore = ["Debug"]`, `OrderedMap` / UTF-16 boundaries, `ui/src/controls/` `SourceLoc`).
- `check_single_invar_pin.sh`: enforces that all `pion/**/pion.toml` (including workspace-inherited and local `path =` identity checks), `pion/**/pion.lock` (requiring `ref == "rev:" + rev`), and `manifest.toml` pin one identical 40-char `AFK-surf/invar` commit SHA.
- `gen_assets.mjs`: direct Pion asset generator for `pion/ui/packages/sf_assets_native/src/` (`--check` is strictly read-only).
- `regen.sh`: deterministic regeneration & `--check` wrapper (always runs real Stage A.5 probes; probe-skipping is intentionally unsupported).
- `test_negative_gates.sh`: 2 positive controls + 5 negative mutation CI gates (`api_map` unit/signature, overlay stale source CST hash, `native` vs `wasm32` code diff, differential oracle dropped/tautologized/real-controls mutations, and single-invar-pin URL/local-path/non-rev-ref enforcement).
- `pilot/`: 22-case 3-engine differential pilot (`moon run --target wasm-gc` vs `pionc run` vs `pionc run --target wasm32`) transpiling and asserting all 6 real `libs/ui/src/controls/*.mbt` production files (`numbers`, `marked`, `tokens_data`, `clock_read_known`, `table_copy`, `reader_marks`) + `pilot_core.mbt` live, plus full production `@ui.css(...)` corpus batch 3-engine parity gate (`pilot/run_css_corpus.sh`, `pilot/extract_css_corpus.py`, `pilot/css_corpus_manifest.json`: 2,096 callsites / 1,237 distinct decoded strings).
- `run_audit_histogram.sh`: byte-reproducible full `@sf` `--mode audit` + `pionc check --json` diagnostic histogram collector writing or read-only verifying (`--check`) `audit_254_histogram.json` and `audit_254_summary.md`.

## Rules

- Never hardcode machine-local paths (`/Users/...`) in committed files; pass `MBT2PION_BIN`, `MBT_COMPAT_DIR`, and `INVAR_DIR` via environment variables.
- Never hand-edit generated `.pion` outputs from `mbt2pion` or `gen_assets.mjs`.
